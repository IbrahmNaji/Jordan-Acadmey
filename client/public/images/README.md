# صور الموقع العام — بيان توضيحي

جميع الصور في هذا المجلد **صور توضيحية مولّدة رقمياً** لبيئة تدريب تقنية عامة، وليست صوراً للمنشأة الفعلية للأكاديمية الأردنية ولا لمتدربيها أو منشآتها.

- تُستخدم مؤقتاً حتى توفير صور فوتوغرافية حقيقية للورشة والأجهزة والمركبات.
- يجب استبدالها بصور الأكاديمية المعتمدة قبل الإطلاق الرسمي، مع الحفاظ على أسماء الملفات نفسها لتجنب تعديل الكود.
- لا يجوز استخدامها كإثبات للمنشأة أو النتائج أو المعدات الفعلية.

## الملفات المقترحة للاستبدال

| الملف | الاستخدام |
| --- | --- |
| `hero/hero-workshop.webp` | خلفية الواجهة الرئيسية |
| `courses/mechanics.webp` | دورة ميكانيك السيارات |
| `courses/electrical.webp` | دورة كهرباء السيارات |
| `courses/diagnostics.webp` | دورة التشخيص الإلكتروني |
| `courses/hybrid.webp` | دورة أنظمة الهايبرد |
| `workshop/practical-training.webp` | قسم التدريب العملي |
| `workshop/workshop-wide.webp` | صفحة الورشة |
| `workshop/instructor.webp` | صفحة عن الأكاديمية |
| `gallery/*.webp` | معرض الورشة |
| `cta-engine.webp` | الدعوة الختامية |

عند استبدال الصور، يُفضّل استخدام WebP بعرض 1200–1920 بكسل للصور الأفقية، وبحد أقصى 300 كيلوبايت لكل صورة.
